### mock змінює роботу функції input(). Без нього тест продовжував би безперервно чекати, поки хтось введе текст із клавіатури. mock дозволяє імітувати цю дію, автоматично підставляючи значення 'Олексій'. Це дозволяє тесту проходити миттєво та самостійно.

### subTest дозволяє перевірити кілька різних наборів даних усередині одного циклу. Його головна перевага полягає в тому, що якщо тест не пройде для першої фігури, перевірка не перерветься - програма протестує всі інші фігури і в звіті чітко вкаже, які саме дані викликали помилку.
